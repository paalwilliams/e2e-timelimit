Import from LeechBlock

In LeechBlock: Options → General → Export Options to Text File (or JSON), then choose the file here. Each block set becomes a list linked to that set number; re-importing replaces them. Keyword, regexp and path-specific patterns can't be enforced by hostname and are skipped.
